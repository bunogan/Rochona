লেখক-প্যানেল

এখান থেকে নতুন লেখা যোগ, পুরনো লেখা সম্পাদনা বা মুছে ফেলা যায়। কাজ করবে শুধু আপনার GitHub চাবি দিয়ে, তাই অন্য কেউ এই পাতা খুললেও কিছু বদলাতে পারবেন না।

ধাপ ১ GitHub সংযোগ সংযুক্ত নয়

চাবি (token) কীভাবে বানাবেন
  1. GitHub-এ লগইন করে Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token।
  2. Repository access-এ শুধু এই সাইটের রিপোজিটরি বেছে নিন।
  3. Permissions → Repository permissions → Contents: Read and write।
  4. বানানো চাবিটি কপি করে ওপরের ঘরে বসান। চাবি শুধু আপনার এই ব্রাউজারে থাকে, কোথাও পাঠানো হয় না।

ধাপ ৩ নতুন লেখা যোগ করুন

PDF কীভাবে দেখাবে

গ্রন্থের ক্ষেত্রে Word ফাইলের "Heading 1" স্টাইল বা "অধ্যায় ১", "অধ্যায় ২"… দিয়ে শুরু হওয়া লাইন থেকে নতুন অধ্যায় ধরা হবে। "প্রথম পর্ব" ধরনের লাইন থেকে পর্ব ধরা হবে।

সম্পাদনার সময় নতুন ফাইল না দিলে আগের লেখা থাকবে, শুধু শিরোনাম, তারিখ ও পরিচিতি বদলাবে।
